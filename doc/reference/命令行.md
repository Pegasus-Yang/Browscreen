# 命令行参考

简体中文 | [English](命令行.en.md)

安装后提供一个入口 `browscreen`。源码安装使用项目根目录的 `.venv/bin/browscreen`，也可以通过 `uv run --no-sync browscreen` 调用；激活虚拟环境后可直接使用下表中的命令。

## 支持的命令

| 命令 | 行为 | 是否需要 `--work-dir` |
| --- | --- | --- |
| `browscreen --help` / `browscreen -h` | 输出全部命令与参数后退出 | 否 |
| `browscreen version` / `browscreen --version` | 输出 `browscreen <安装版本>` 后退出 | 否 |
| `browscreen --work-dir <目录>` | 启动一个 HTTP 服务和一个采集循环 | 是 |

版本信息读取已安装包的元数据，与 FastAPI 的 OpenAPI 版本一致。版本查询不会启动服务或读写交换文件；`-v` 用于 DEBUG 日志，查询版本请使用 `version` 或 `--version`。

## 启动参数

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `--work-dir` | 必填 | 已存在的交换目录，启动时转换为绝对路径 |
| `--adapter` | `chrome-cdp` | 浏览器适配器，目前仅支持此值 |
| `--interval-ms` | `300` | 正整数；截图目标间隔、预览轮询及失败重试间隔，单位毫秒 |
| `--connect-wait-timeout-s` | `60` | 大于零的有限秒数；启动或恢复至首个有效帧的总预算 |
| `--host` | `127.0.0.1` | HTTP 监听地址 |
| `--port` | `8000` | HTTP 端口，范围 `1` 至 `65535` |
| `-v` / `--verbose` | 关闭 | 开启 DEBUG 诊断日志与 HTTP 访问日志 |
| `--record` | 关闭 | 开启 MP4 视频录制，需要安装 `browscreen[video]` |
| `--record-output` | 系统临时目录内的唯一文件 | 完整 `.mp4` 文件路径；必须同时开启 `--record`，父目录已存在，不覆盖已有文件 |

未知命令、非法参数或无效工作目录以退出码 `2` 结束；帮助和版本查询成功时退出码为 `0`。

录制缺少可选依赖或编码器时输出友好的安装提示，以退出码 `1` 结束。仅提供输出路径不能开启录制；相对路径按进程启动目录解析，展开 `~`，不以 `--work-dir` 为输出根目录。帮助和版本查询不加载视频依赖。

```sh
.venv/bin/browscreen version
.venv/bin/browscreen --work-dir /absolute/path/to/workspace
.venv/bin/browscreen -v --work-dir /absolute/path/to/workspace --port 8001
.venv/bin/browscreen --work-dir /absolute/path/to/workspace --record
.venv/bin/browscreen --work-dir /absolute/path/to/workspace --record \
  --record-output /absolute/path/to/recordings/session.mp4
```

`-v` 可放在启动参数前后。通过 uv 启动时，将其写在 `browscreen` 后，例如 `uv run --no-sync browscreen -v --work-dir <目录>`，以将参数传给服务。

## 日志级别

| 场景 | 默认 INFO 模式 | `-v` DEBUG 模式 |
| --- | --- | --- |
| HTTP 启动与关闭 | 保留 | 保留并增加诊断信息 |
| 首次等待、首帧就绪、画面恢复 | 每次状态变化记录一次 | 同左 |
| 端点等待、连接失败、截图重试 | 省略重复细节；等待超时仍告警 | 输出每次重试及其原因 |
| 网页和图片接口的 HTTP 访问 | 省略 | 开启 Uvicorn 访问日志 |
| HTTPX、WebSocket、PNG 库诊断 | 默认仅保留 WARNING 及以上 | 开启 DEBUG |
| webhook 连续失败 | 同一地址首次失败告警，恢复记录 INFO，再次失败重新告警 | 连续失败的每帧细节记录 DEBUG |
| 清空 `.mouse` 成功 | 省略 | 记录 DEBUG |
| 录制开启与服务结束时的结果 | 输出目标路径及完成、部分视频或未生成摘要 | 同左 |
| 运行中录制失败 | 立即报告 ERROR，停止录制，截图与 webhook 继续 | 同左 |
| 未预期异常、连接或文件清理失败 | 保留 ERROR 和堆栈 | 同左 |

日志去重不改变重试间隔、等待预算、截图频率或 webhook 的逐帧发送规则。DEBUG 日志可能包含端点、本机路径和协议内容，公开提交日志前应删除敏感信息。

环境准备、安装和退出方式见[安装与运行](../deployment/安装与运行.md)，文件及接口约定见[使用说明](../user-guide/使用说明.md)。
