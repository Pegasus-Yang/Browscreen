## 阶段五：webhook 注册和逐帧推送

| 编号 | 操作或验证方法 | 通过标准 | 结果 |
| --- | --- | --- | --- |
| S5-01 | 注册合法 HTTP(S) 地址、重复地址和非法地址 | 首次 `201`、重复 `200` 且只保留一份；非法请求按 Pydantic 校验失败 | 通过 |
| S5-02 | 注册两个本地接收器，核对连续新帧 | 注册生效后的每张新帧对每个唯一地址尝试一次；注册前历史帧不回放 | 通过 |
| S5-03 | 按帧编号比对发送端与接收端字节哈希、元数据 | PNG 二进制、Content-Type、帧编号和时间一致；包含与网页相同的合成指针 | 通过 |
| S5-04 | 一接收器成功，另一拒绝连接、返回非 2xx 或超时 | 各地址发送彼此独立，失败有日志，采集继续；每次总耗时受 3 秒截止时间约束 | 通过 |
| S5-05 | 接收器延迟超过 300 毫秒 | 采集按等待策略降频，已生成帧仍各尝试一次，没有无界队列或后台任务增长 | 通过 |

接口查询可能已经读到更新的帧，应先核对编号；不要求不同帧的图片哈希相同。证据：注册响应、本地接收器记录、发送日志和图片哈希。

## 阶段六：地址失效、恢复与关闭

| 编号 | 操作或验证方法 | 通过标准 | 结果 |
| --- | --- | --- | --- |
| S6-01 | 正常采集时断开 CDP、关闭页面或制造协议超时 | 释放自身旧连接、清空图片缓存并进入新的恢复等待；网页隐藏旧画面 | 通过 |
| S6-02 | 失效后将 `.cdp` 更新为另一可用地址 | 从文件读新地址，截止前恢复新页面截图，webhook 注册仍有效 | 通过 |
| S6-03 | `.cdp` 地址不变，原 CDP 服务在截止前恢复 | 原地址也能重连，不要求必须改文件内容 | 通过 |
| S6-04 | 恢复期一直失败，到期后修正文件并重启服务 | 到期停止轮询并报告超时；重启开始新一轮等待，重新注册 webhook 后可推送 | 通过 |
| S6-05 | 关闭截图服务，检查目标 Chrome | 后台任务、WebSocket 和 HTTPX 连接已释放；没有发送关闭浏览器或标签页的命令，目标浏览器继续运行 | 通过 |
| S6-06 | 外部停止写入后，分别正常停止和 SIGINT／SIGTERM 优雅退出服务；包含 `.mouse` 缺失情况 | 已有 `.mouse` 保留且变为零字节；不存在时不创建；`.cdp` 内容不变 | 通过 |
| S6-07 | 退出清空后同目录重启，先不写新坐标，再由外部写入新坐标 | 无上次指针残留；新有效坐标正常绘制 | 通过 |
| S6-08 | CDP 断线或等待超时，保持 HTTP 服务运行并检查文件 | 只清空图片缓存，不清空 `.mouse`；坐标继续由外部系统控制 | 通过 |

主服务负责浏览器启动、参数、端口和环境隔离；本阶段由测试准备方模拟这些外部操作，本服务只连接所提供的端点。退出清空验证按正常停止和优雅退出执行。

证据：恢复前后地址、帧和状态记录，超时／关闭日志，退出后的文件内容与重启截图，相关 pytest 输出。

## 阶段七：本机无头 Chrome 最终验收

执行步骤见[具体实施方案第四节](具体实施方案.md#四本机最终验收操作)。以下项目必须实际通过，不能由模拟测试替代。

| 编号 | 本机操作 | 最终通过标准 | 结果 |
| --- | --- | --- | --- |
| F-01 | 验证人员模拟主服务，以独立数据目录启动 `--headless` Chrome，访问 `https://ceshiren.com` | 浏览器由服务外部启动，无可见目标 Chrome 窗口，CDP 可连接；目标 URL、标题和实际页面内容可核对 | 通过 |
| F-02 | `.cdp` 写入该实例地址，启动服务；可见浏览器打开服务网页 | **在本服务预览页面中看到目标网站的真实画面**，图片加载有非零尺寸；不是空白、错误或验证拦截页 | 通过 |
| F-03 | 连续观察至少 30 秒并查询图片接口 | 不同新帧编号与时间持续更新，无卡死；记录实际间隔，满足既定非重叠调度规则 | 通过 |
| F-04 | 在 `.mouse` 写入 A 点 `(320,180)`，记录实际 CSS 和 PNG 尺寸 | 服务网页可见合成指针；按实际比例独立计算，PNG 热点每轴偏差不超过 1 像素 | 通过 |
| F-05 | 改成 B 点 `(640,360)` | 下一轮读取后的新帧中热点移动到 B 点，A 点无旧箭头残留 | 通过 |
| F-06 | 清空 `.mouse`，再检查非法、越界及删除文件 | 新帧不绘制指针，网页保持更新，不复用最后有效坐标 | 通过 |
| F-07 | 恢复 A 点，将预览图片显示宽度缩到一半 | 按图片实际内容区换算后指针位置仍对齐，图片和指针一起缩放 | 通过 |
| F-08 | 停止外部坐标写入，正常退出预览服务，检查文件并同目录重启；之后外部写入新坐标 | `.mouse` 保留且为零字节，`.cdp` 未变，Chrome 仍运行；重启后无旧指针，新坐标正常绘制 | 通过 |
| F-09 | 保存证据并执行全部相关 pytest，填写阶段与总结果 | 阶段一至六和 F-01 至 F-08 均有通过证据，无未解释的失败；报告包含真实运行版本和时间 | 通过 |

A、B 必须处于实际视口内；必要时换为视口内坐标并记录。`--window-size` 不能代替实际 CSS 视口测量。真实网站动态变化时，固定图片测试证明合成像素正确，真实服务页截图证明位置显示正确，不能将两帧的全部差异都视为指针。

**总验收结论：通过。** 网络或网站状态导致无法完成 F-02 时应记录原因并重测，不能替换最终目标网站或仅凭图片接口返回 `200` 标为完成。
