# 安装与运行

简体中文 | [English](安装与运行.en.md)

browscreen 使用 Python 3.14、项目根 `.venv/` 和 `uv.lock`。浏览器、CDP 地址、工作目录及端口由主服务或测试准备方提供。

## 安装

在项目根目录执行：

```sh
uv venv --python 3.14 .venv
uv sync --locked --no-dev \
  -i http://mirrors.aliyun.com/pypi/simple/ \
  --trusted-host mirrors.aliyun.com
.venv/bin/python -V
.venv/bin/browscreen --help
.venv/bin/browscreen version
```

已有 Python 3.14 时直接使用；需要安装解释器时先执行 `uv python install 3.14`。项目使用 `src/browscreen/` 打包，安装后从根目录即可导入，无需配置 `PYTHONPATH`。受限执行环境无法写入 uv 默认缓存时，可给上述 uv 命令设置 `UV_CACHE_DIR=/private/tmp/browscreen-uv-cache`。

安装后仅提供 `browscreen` 入口。帮助、版本查询、全部启动参数及日志说明见[命令行参考](../reference/命令行.md)。当前未提供独立的浏览器启动命令，Chrome 由调用方管理。

## 安装可选视频依赖

基础依赖不包含 PyAV。录制需要另外同步 `video` extra：

```sh
uv sync --locked --no-dev --extra video \
  -i http://mirrors.aliyun.com/pypi/simple/ \
  --trusted-host mirrors.aliyun.com
```

发布包安装使用 `uv pip install 'browscreen[video]'`，追加同样的镜像源参数；安装本地 wheel 时使用 `"${wheel_file}[video]"`。匹配的 PyAV 二进制 wheel 包含 FFmpeg 库，无需另装 FFmpeg 命令。开启录制但缺少或无法加载 PyAV 时，CLI 输出上述安装提示并以退出码 `1` 结束；移除录制参数即可使用基础功能。

## 启动

外部系统先准备一个已有工作目录，并将可达 Chrome 调试地址写入固定文件 `.cdp`。例如 `.cdp` 内容为 `http://127.0.0.1:9222`，之后执行：

```sh
uv run --no-sync browscreen \
  --work-dir /absolute/path/to/workspace \
  --adapter chrome-cdp \
  --interval-ms 300 \
  --connect-wait-timeout-s 60 \
  --host 127.0.0.1 \
  --port 8000
```

打开 `http://127.0.0.1:8000/` 查看只读画面。首次尚未提供 `.cdp` 时，HTTP 立即可用，并在 60 秒等待期内持续重读文件。正常连接不主动切换被改写的地址；连接或页面失效后，重新读取 `.cdp` 并进入独立的恢复等待。到期后 HTTP 保留，采集停止；修正文件后重启服务。

默认以 INFO 级别记录状态变化、超时和异常，省略逐请求和重复重试细节。排查问题时在 `browscreen` 后追加 `-v` 或 `--verbose`，开启 DEBUG 与 HTTP 访问日志。

每轮等待持续到首个有效 PNG 生成，期间反复连接成功但截图失败不会重置截止时间。收到 `capture_failed` 时，采集任务已因未预期异常停止，查看服务日志中的堆栈、修正原因后重启。

只运行一个 Uvicorn worker。主服务以 SIGINT 或 SIGTERM 正常结束子进程，并等待其退出；此时已有 `.mouse` 保留且内容清空，`.cdp` 保留，Chrome 继续运行。浏览器启动、访问和最终回收由外部系统管理。

安装 extra 后，追加 `--record` 即可录制；追加 `--record-output /absolute/path/to/recordings/session.mp4` 指定完整文件路径。父目录须已存在，服务排他创建文件，拒绝覆盖。未指定时采用系统临时目录，退出后从 INFO 日志获取绝对路径。临时文件保留至用户或系统清理；长期保存请指定位置。

录制采集任务结束时会立即收尾，等待超时后的 HTTP 服务仍可访问。服务退出时输出一次最终录制结果；没有有效帧时删除空文件并说明未生成视频。录制编码增加每轮耗时，运行中的录制错误停止录制并报告原因，截图和 webhook 继续工作。SIGKILL、崩溃及强制中断无法保证 MP4 可播放；调用方应等待正常退出。详细约定见[视频录制说明](../user-guide/使用说明.md#可选视频录制)。

## 验证与构建

完整测试需要 Node.js 22 或更高版本运行预览脚本回归，无需安装 npm 依赖。缺少 Node 时，pytest 会明确跳过该项；这种结果不代表前端验证通过。Python 测试使用项目根 `.venv/`。

默认 pytest 使用模拟浏览器端点，不启动真实 Chrome。真实浏览器验证须另行执行，并使用独立临时数据目录；操作步骤见[实施方案](../design/具体实施方案.md#四本机最终验收操作)。

```sh
uv sync --locked --group dev \
  -i http://mirrors.aliyun.com/pypi/simple/ \
  --trusted-host mirrors.aliyun.com
.venv/bin/python -m pytest -q -W error
uv build \
  -i http://mirrors.aliyun.com/pypi/simple/ \
  --trusted-host mirrors.aliyun.com
```

构建生成源码包和 wheel。wheel 包含 `preview.html`、`assets/cursor.png`、命令入口及 MIT 许可证。审核与验收记录、运行日志和交换文件不随构建产物分发。

在部署目录中安装已构建 wheel 时，先创建该目录的 `.venv/`，再指定实际 wheel 路径：

```sh
uv venv --python 3.14 .venv
wheel_file="/absolute/path/to/browscreen-0.3.1-py3-none-any.whl"
uv pip install --python .venv/bin/python "$wheel_file" \
  -i http://mirrors.aliyun.com/pypi/simple/ \
  --trusted-host mirrors.aliyun.com
.venv/bin/browscreen version
```
