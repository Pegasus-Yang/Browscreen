# browscreen 使用说明

简体中文 | [English](使用说明.en.md)

browscreen 连接外部启动的 Chrome，默认每 300 毫秒采集当前视口。一个采集循环生成完整 PNG，网页、图片接口和 webhook 共用该帧；有有效坐标时，PNG 已包含合成指针。

## 工作目录文件

`.cdp` 是 UTF-8 单行地址，允许 BOM 和末尾换行。支持 Chrome 的 HTTP(S) 调试根入口、浏览器级 WebSocket 及页面级 WebSocket。浏览器级入口选择返回列表中首个已有页面；精确指定页面时写入对应 `/devtools/page/...` 地址。

`.mouse` 是一个文本坐标对，例如 `320,180` 或 `320.5, 180.0`。坐标单位是当前可见视口的 CSS 像素，原点位于其左上角。服务每轮重新读取；空值、缺失、非法、非有限值及视口外坐标使新帧不绘制指针。有效坐标持续显示，直到外部系统改变文件。Chrome 的完整 CSS 视口采用 `window.innerWidth/innerHeight`，与完整视口 PNG 对应；PNG 缩放比例由适配器数据计算。

正常停止或优雅退出会清空已有 `.mouse`，保留文件。同目录重启后，外部写入新坐标即可再次显示指针。运行中的重连和等待超时不会改写 `.mouse`。

## 预览与图片接口

`GET /` 返回只读预览页，按配置间隔依次查询图片，不重叠请求。图片等比缩放，失败时隐藏旧画面。预览页上的鼠标和键盘操作不转发到目标浏览器。

每轮预览读取与图片加载最长等待 5 秒，超时会隐藏旧画面并自动重试。离开页面时取消请求，从浏览器历史缓存返回后自动恢复更新。同一帧重复返回时跳过重复的图片加载；服务重启后帧号变小也能正常更新。

`GET /api/screenshot` 返回最新 `image/png`，包含：

| 响应头 | 含义 |
| --- | --- |
| `Cache-Control: no-store` | 不缓存响应 |
| `X-Frame-Id` | 进程内递增帧编号，重连继续递增 |
| `X-Capture-Started-At` | 本轮采集开始的 UTC 时间 |

无图片时返回 `503` JSON：`waiting_for_browser` 表示等待端点，`screenshot_not_ready` 表示连接成功但首帧尚未产生，`browser_wait_timeout` 表示等待到期，需要重启服务；`capture_failed` 表示采集任务异常停止，需要检查服务日志后重启。

启动或故障恢复的等待预算持续到首个有效图片生成；即使连接成功，连续截图失败也不会重置预算。非法端点可在该预算内修正，服务按配置间隔重新读取。

## 页面悬浮窗示例

已有网页可以用 `iframe` 嵌入服务的预览页，以可拖动、可调整大小、带放大／还原和关闭按钮的悬浮窗显示实时画面。先按[安装与运行](../deployment/安装与运行.md)启动 browscreen，确认浏览器可以打开 `http://127.0.0.1:8000/` 并看到持续更新的画面，再将下面完整的样式、HTML 和脚本一起放在业务页面的 `</body>` 前：

```html
<style>
  #browscreen-floating-window { position: fixed; right: 16px; bottom: 16px; width: min(480px, calc(100% - 32px)); height: min(480px, calc(100% - 32px)); display: flex; flex-direction: column; box-sizing: border-box; z-index: 10000; overflow: hidden; border: 1px solid #d1d5db; border-radius: 12px; background: #fff; box-shadow: 0 8px 32px #0002; font: 14px system-ui, sans-serif; color: #202632; }
  #browscreen-floating-window .browscreen-titlebar { display: flex; align-items: center; gap: 8px; flex: 0 0 44px; padding: 0 10px 0 16px; border-bottom: 1px solid #e5e7eb; cursor: move; touch-action: none; user-select: none; }
  #browscreen-floating-window .browscreen-caption { flex: 1; min-width: 0; overflow: hidden; white-space: nowrap; text-overflow: ellipsis; }
  #browscreen-floating-window button { padding: 6px 8px; border: 0; border-radius: 6px; background: transparent; color: inherit; font: inherit; cursor: pointer; }
  #browscreen-floating-window button:hover { background: #f3f4f6; }
  #browscreen-floating-window button:focus-visible { outline: 2px solid #2563eb; }
  #browscreen-floating-window iframe { flex: 1; min-height: 0; width: 100%; border: 0; background: #f3f4f6; }
  #browscreen-floating-window .browscreen-resize { position: absolute; right: 0; bottom: 0; width: 24px; height: 24px; cursor: nwse-resize; touch-action: none; }
  #browscreen-floating-window .browscreen-resize::after { content: ''; position: absolute; right: 6px; bottom: 6px; width: 10px; height: 10px; border-right: 2px solid #64748b; border-bottom: 2px solid #64748b; }
  #browscreen-floating-window.browscreen-moving iframe { pointer-events: none; }
  #browscreen-floating-window.browscreen-maximized .browscreen-resize { display: none; }
  #browscreen-floating-window.browscreen-maximized .browscreen-titlebar { cursor: default; }
</style>
<section id="browscreen-floating-window" aria-label="浏览器实时画面">
  <div class="browscreen-titlebar">
    <span class="browscreen-caption">浏览器实时画面</span>
    <button type="button" data-action="maximize" aria-pressed="false">放大</button>
    <button type="button" data-action="close" aria-label="关闭实时画面">关闭</button>
  </div>
  <!-- 修改 src 为当前浏览器可访问的 browscreen 服务根地址。 -->
  <iframe id="browscreen-preview-window" src="http://127.0.0.1:8000/" title="browscreen 实时画面（只读）"></iframe>
  <div class="browscreen-resize" title="拖动右下角调整大小" aria-hidden="true"></div>
</section>
<script>
(() => {
  const panel = document.getElementById('browscreen-floating-window');
  const titlebar = panel.querySelector('.browscreen-titlebar');
  const grip = panel.querySelector('.browscreen-resize');
  const maximize = panel.querySelector('[data-action="maximize"]');
  const events = new AbortController();
  const options = { signal: events.signal };
  const margin = 16;
  let rect, savedRect, gesture = null;
  let expanded = false;
  const viewport = () => ({ width: document.documentElement.clientWidth, height: document.documentElement.clientHeight });
  const clamp = (value, min, max) => Math.max(min, Math.min(max, value));

  function draw(next) {
    const size = viewport();
    const maxWidth = size.width - margin * 2;
    const maxHeight = size.height - margin * 2;
    const width = clamp(next.width, Math.min(280, maxWidth), maxWidth);
    const height = clamp(next.height, Math.min(200, maxHeight), maxHeight);
    rect = { width, height, x: clamp(next.x, margin, size.width - margin - width), y: clamp(next.y, margin, size.height - margin - height) };
    Object.assign(panel.style, { left: `${rect.x}px`, top: `${rect.y}px`, right: 'auto', bottom: 'auto', width: `${width}px`, height: `${height}px` });
  }

  function fillViewport() {
    const size = viewport();
    draw({ x: margin, y: margin, width: size.width - margin * 2, height: size.height - margin * 2 });
  }

  function start(event, mode) {
    if (!event.isPrimary || event.button !== 0 || expanded || event.target.closest('button')) return;
    gesture = { mode, pointerId: event.pointerId, handle: event.currentTarget, x: event.clientX, y: event.clientY, rect: { ...rect } };
    gesture.handle.setPointerCapture(event.pointerId);
    panel.classList.add('browscreen-moving');
    event.preventDefault();
  }

  function move(event) {
    if (!gesture || event.pointerId !== gesture.pointerId) return;
    const dx = event.clientX - gesture.x;
    const dy = event.clientY - gesture.y;
    const before = gesture.rect;
    if (gesture.mode === 'drag') {
      draw({ ...before, x: before.x + dx, y: before.y + dy });
    } else {
      const size = viewport();
      draw({ ...before, width: clamp(before.width + dx, Math.min(280, size.width - margin * 2), size.width - margin - before.x), height: clamp(before.height + dy, Math.min(200, size.height - margin * 2), size.height - margin - before.y) });
    }
  }

  function stop(event) {
    if (!gesture || event.pointerId !== gesture.pointerId) return;
    const { handle, pointerId } = gesture;
    gesture = null;
    panel.classList.remove('browscreen-moving');
    if (handle.hasPointerCapture(pointerId)) handle.releasePointerCapture(pointerId);
  }

  for (const [handle, mode] of [[titlebar, 'drag'], [grip, 'resize']]) {
    handle.addEventListener('pointerdown', event => start(event, mode), options);
    handle.addEventListener('pointermove', move, options);
    for (const type of ['pointerup', 'pointercancel', 'lostpointercapture']) handle.addEventListener(type, stop, options);
  }
  maximize.addEventListener('click', () => {
    expanded = !expanded;
    if (expanded) { savedRect = { ...rect }; fillViewport(); }
    else draw(savedRect);
    panel.classList.toggle('browscreen-maximized', expanded);
    maximize.textContent = expanded ? '还原' : '放大';
    maximize.setAttribute('aria-pressed', String(expanded));
  }, options);
  panel.querySelector('[data-action="close"]').addEventListener('click', () => {
    events.abort();
    panel.remove();
  }, options);
  window.addEventListener('resize', () => expanded ? fillViewport() : draw(rect), options);
  const size = viewport();
  draw({ x: size.width - 496, y: size.height - 496, width: 480, height: 480 });
})();
</script>
```

只需修改 `iframe` 的 `src` 服务地址。完整 HTML 文件见[实时画面悬浮窗示例](examples/实时画面悬浮窗.html)，修改地址后可用浏览器打开；接入业务页面时复制其中“悬浮窗开始”到“悬浮窗结束”之间的全部代码。

- 拖动标题栏移动窗口，拖动右下角调整大小；鼠标和触摸操作使用 [Pointer Events](https://developer.mozilla.org/en-US/docs/Web/API/Pointer_events)。
- 点击“放大”铺满视口内的可用区域，点击“还原”恢复此前的位置和大小。这里调整的是窗口尺寸，图片仍等比显示。
- 点击“关闭”移除窗口和 iframe，并清理事件监听；再次显示时重新插入这段代码或刷新页面。
- 初始窗口为 480×480 像素；一般最小尺寸为 280×200，小屏幕下会进一步缩小以适应视口。拖动、调整尺寸及浏览器窗口变化后，悬浮窗均限制在页面可见区域内。调整尺寸时右侧和底部需要留有空间，可以先将窗口向左上方移动。

窗口内复用服务已有的 PNG 轮询、图片等比缩放、超时重试和不可用状态提示，更新间隔沿用服务的 `--interval-ms` 配置。每次读取的是缓存的最新帧，不会额外触发截图；窗口中的鼠标和键盘操作不控制目标浏览器。

父页面与服务可以使用不同端口或域名，图片请求在预览页内部发往服务自身，因此这个示例无需新增 CORS 配置。接入时注意：

- `127.0.0.1` 指访问网页的用户自己的机器。服务部署在其他机器时，替换为该用户浏览器可访问的服务根地址。
- HTTPS 业务页面接入远程服务时，使用 HTTPS 服务根地址，例如 `https://preview.example.com/`；普通 HTTP 地址可能被[混合内容规则](https://developer.mozilla.org/en-US/docs/Web/Security/Defenses/Mixed_content)拦截。若浏览器提示[本地网络访问权限](https://developer.chrome.com/blog/local-network-access)，须允许访问才能连接本机或局域网服务。
- 业务页面设置了 CSP 时，需要在 [`frame-src`](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Content-Security-Policy/frame-src) 中允许预览服务地址；若限制内联样式或脚本，将示例中的样式和脚本移到业务页面允许加载的 CSS／JS 文件中，或按业务页面的 nonce／哈希策略接入。

## webhook

使用 `POST /api/webhooks` 注册：

```sh
curl -X POST http://127.0.0.1:8000/api/webhooks \
  -H 'Content-Type: application/json' \
  -d '{"url":"http://127.0.0.1:9001/on-screenshot"}'
```

首次注册返回 `201`，规范化后的重复地址返回 `200`，正文为 `{"url":"http://127.0.0.1:9001/on-screenshot","registered":true}`。记录只在当前进程内保留，重连继续使用，服务重启后重新注册。

每个新帧向注册时生效的唯一地址并发 `POST` 一次。正文为 PNG 二进制，`Content-Type: image/png`，帧编号和开始时间与图片接口一致。接收器直接读取请求 body 即可。

所有发送尝试完成后才进入下一轮采集。单次发送受 3 秒总时间限制；失败记录日志、不自动重试、不跟随重定向。慢接收器会降低实际采集频率，已生成的帧仍逐地址尝试发送。注册不回放历史帧，成功送达不属于发送尝试的保证。

默认日志对同一接收地址的连续失败只在首次输出 WARNING，后续细节保留在 DEBUG；恢复时输出一次 INFO，再次失败重新告警。每帧的实际发送尝试保持不变，开启方式见[命令行参考](../reference/命令行.md)。

## 可选视频录制

安装 `browscreen[video]` 或在源码环境中执行 `uv sync --extra video`，追加项目指定镜像源参数，之后用 `--record` 开启录制：

```sh
uv run --no-sync browscreen --work-dir /absolute/path/to/workspace --record
uv run --no-sync browscreen --work-dir /absolute/path/to/workspace --record \
  --record-output /absolute/path/to/recordings/session.mp4
```

不传 `--record` 时不加载 PyAV、创建录制器或生成文件。缺少依赖但开启录制时，CLI 输出安装提示并以退出码 `1` 结束。完整安装步骤见[安装可选视频依赖](../deployment/安装与运行.md#安装可选视频依赖)。

`--record-output` 指定完整的 `.mp4` 文件路径，后缀大小写不敏感；展开 `~`，相对路径按进程启动目录解析。父目录必须已存在，已有文件不会覆盖，仅提供此参数会报配置错误。未指定时使用系统临时目录生成唯一文件。

视频为 H.264、`yuv420p`、无音轨的 MP4，包含合成 PNG 中的指针。录制复用当前采集结果，不启动额外截图循环。视频从第一张有效帧开始，采用实际采集开始时间确定画面切换；慢采集、编码或 webhook 等待不会被压缩为快速播放。浏览器暂时断开时保留上一张已知画面到恢复或采集结束，这不表示断线期间页面没有变化。

第一张 PNG 的实际尺寸决定视频画布，奇数宽高在右侧和底部补齐至偶数。后续截图尺寸变化时等比例缩放并居中补黑边，保持完整内容；原截图接口尺寸不受影响。编码固定使用 `libx264`、`veryfast` 和 CRF `18`，逐帧等待，不积压或主动丢帧，可能降低实际采集频率及推迟 webhook。

正常结束时，发送 SIGINT 或 SIGTERM 并等待服务退出，完成编码刷新和 MP4 关闭。默认 INFO 日志会输出：

```text
录制完成，视频文件：/absolute/path/to/recordings/session.mp4
```

路径是实际文件的绝对路径，正常视频退出后保留；临时目录之后可能被系统清理，长期保存请指定路径或复制文件。若始终没有有效帧，会删除空文件并输出“未生成视频：未获取到有效截图”。

浏览器恢复超时或采集异常停止时先收尾视频，HTTP 服务仍按原规则工作；服务结束时说明录制提前结束及部分视频位置。运行中发生视频处理或写入错误时，停止录制、尝试收尾并报告错误，截图与 webhook 继续运行。本次运行不自动重启录制。收尾失败会报告残留路径及可能无法播放的结果。SIGKILL、崩溃和强制中断不能保证收尾或输出位置。

安装、启动参数和退出方式见[安装与运行](../deployment/安装与运行.md)，初始服务设计见[设计方案](../design/设计方案.md)，录制设计依据见[可选视频录制实现方案](../design/可选视频录制实现方案.md)。
